# Rally de la Independencia AR (dolores_rally)

Proyecto Flutter listo para ejecutar.

Desde esta carpeta:

1. `flutter pub get`
2. `flutter test`
3. `flutter run -d chrome` (o `flutter run` para el dispositivo conectado)

Al iniciar, pulsa **Modo demo (salón de clases)** para jugar sin GPS. En un
dispositivo Android o iPhone puedes elegir **Jugar en Dolores Hidalgo (GPS
real)**; los permisos de cámara y ubicación ya están declarados en las
configuraciones de Android e iOS.

Para compilar Android se requiere Android Studio con Android SDK y licencias
aceptadas. Para compilar Windows se requiere Visual Studio con la carga
**Desktop development with C++**.
